Автотесты для Кинопоиска

## Описание проекта
Автоматизированные UI и API тесты для сайта Кинопоиск

## Структура проекта
- `tests/` - тесты (UI и API)
- `pages/` - Page Object модели для UI тестов
- `api/` - клиент для работы с API Кинопоиска
- `config/` - настройки проекта
